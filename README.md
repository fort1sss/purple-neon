# purple-neon

Мод для Claude: неонова помаранчева рамка навколо твоїх повідомлень у чаті.

## Встановлення

У терміналі Claude Code:

```
/plugin install purple-neon --marketplace fort1sss/purple-neon
```

Або в shell:

```
claude plugin install purple-neon --marketplace fort1sss/purple-neon
```

У десктоп-застосунку Claude: натисни **+** біля поля вводу → **Plugins** → **Add marketplace** → `fort1sss/purple-neon` → **Add plugin**.
